# Cats vs Dogs MLOps Assignment 2

This project implements an end-to-end MLOps pipeline for binary image classification of cats and dogs.

## Main Components

- Data preprocessing to 224x224 RGB images
- Train/validation/test split
- CNN model training
- MLflow experiment tracking
- FastAPI inference service
- Docker containerization
- Pytest automated testing
- GitHub Actions CI/CD
- Docker image publishing
- Deployment using Docker Compose or Kubernetes
- Logging and metrics monitoring
